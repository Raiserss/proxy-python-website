# Proxy Python Workspace

Selamat datang di portal informasi resmi dan portofolio interaktif Kelompok Proxy Python.

// PROFILE KELOMPOK Active Project

Proxy Python adalah kelompok kolaboratif yang bergerak di bidang eksplorasi pemrograman, rekayasa perangkat lunak, dan pengembangan aplikasi web. Website ini didesain secara khusus menyerupai lingkungan kerja Visual Studio Code (IDE) untuk memberikan pengalaman interaktif, modern, dan profesional saat menelusuri profil anggota maupun dokumentasi proyek kelompok.

## Fitur-Fitur & Panduan Penggunaan Website

1. Navigasi Berbasis IDE Editor

Navigasi berpindah tab secara dinamis di bagian atas layaknya membuka berkas kode pada VS Code. Disertai penunjuk lokasi (*breadcrumb bar*) yang menyesuaikan secara otomatis.

2. Card Biodata & Pratinjau ATS CV

Menampilkan biodata anggota lengkap dengan format variabel syntax Python. Dilengkapi tombol modal untuk melihat pratinjau dokumen CV ATS secara langsung di website tanpa perlu berpindah halaman.

3. Galeri Dokumentasi (Lightbox)

Kumpulan foto kegiatan dan pengerjaan proyek kelompok. Dilengkapi fitur *Lightbox Viewer* interaktif untuk memperbesar foto beserta penjelasan detailnya.

4. Toggle Primary Sidebar Fleksibel

Tekan tombol ikon garis tiga di pojok kiri atas (*Header*) untuk menyembunyikan atau menampilkan panel *Explorer Sidebar* secara instan baik di komputer maupun HP.
